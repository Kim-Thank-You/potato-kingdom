⚡ 자동 테스트
📊 상태 전이표
🌱 Farm Slot
empty → doPlant → growing → timer → harvestable
harvestable → doHarvest → empty (재심기)
harvestable → doHarvest(×2) → empty (광고 2배)
growing → doInstantHarvest → harvestable (💎 소모)
locked → doUnlockSlot → empty (💎 소모)
🎮 Game → Farm/Guild
puzzle → +POTATO, +guildContrib, farmBoost(-30m)
battle → +POTATO, +guildContrib
🏰 Guild
none → applyToGuild → applied → api → pending
pending → approveGuildJoin → joined
joined → leaveGuild → none
doCreateGuild → leader
leader → leaveGuild → none (길드 해산)
👥 Referral
friendHarvest → pendingPotato ↑
claimReferralBonus → pending→potato, Vault 로그
💰 Settlement
주간: guildProgress 판정 → monthlyPendingTon ↑ (pending 로그)
월간: monthlyPendingTon → monthlyConfirmedTon → S.ton (confirmed 로그)
출금: S.ton → withdrawn (withdrawn 로그)
✅ 수동 검수 순서
1. Farm 탭 → 1번 빈 땅 → 🌱 씨앗 심기 → growing 전환 확인
2. 성장 중 → 예상 수확량 표시 확인 → 타이머 작동 확인
3. 💎 즉시 수확 → 다이아 차감 → harvestable 전환 확인
4. 🥔 수확하기 → POTATO 증가 → empty 전환 → 재심기 버튼 확인
5. 🔥 광고 2배 수확 → 2배 POTATO 확인 → Vault 로그 확인
6. Game 탭 → PLAY NOW → 퍼즐 결과 모달 확인
7. 결과 모달에서 POTATO / 길드 기여도 / 농장 부스트 표시 확인
8. 수호전 출정 → 전투 → 나가기 → POTATO 증가 확인
9. Guild 탭 → 길드 찾기 → 신청 → applied 상태 확인
10. pending 전환 → 승인 시뮬 → joined 전환 확인
11. joined 상태 → 유효자 대시보드 → 미달 항목 빨간 표시 확인
12. Farm 탭 → 친구 보너스 카드 → 수령 버튼 → POTATO 증가 확인
13. Vault 탭 → TON/POTATO/DIAMOND 내역 렌더 확인
14. 💠 출금 신청 → 바텀시트 → 수치 일치 확인
15. CTA 배너가 수확/퍼즐/정산 후 즉시 갱신되는지 확인
